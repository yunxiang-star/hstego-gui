# opencode 智能体 · 使用说明

## 这个文件夹是什么

一份**隐写课题专属的 opencode 配置模板**。把它拷进你的真实项目目录，opencode 就变成
"懂你这个课题"的智能体了。

---

## 一、怎么用（三步）

### 第 1 步：装好了，不用你管

已经装完：

| 东西 | 位置 |
|---|---|
| opencode 本体 | `C:\Users\ILLENIUM\.opencode\node_modules\.bin\opencode.cmd`（已加入用户 PATH） |
| VSCode 扩展 | `sst-dev.opencode` v0.0.13 |
| 模型凭据 | `C:\Users\ILLENIUM\.local\share\opencode\auth.json`（DeepSeek） |
| 全局配置 | `C:\Users\ILLENIUM\.config\opencode\opencode.jsonc` |

### 第 2 步：把这个文件夹拷到项目里

把下面 **3 样东西**一起拷到你的隐写项目根目录：

```
AGENTS.md          →  项目根/AGENTS.md
opencode.jsonc     →  项目根/opencode.jsonc
.opencode/         →  项目根/.opencode/
```

（`使用说明.md` 不用拷，那是我写给你看的。）

### 第 3 步：填 TODO

打开 `AGENTS.md`，里面有两处 `TODO`：
- **目录结构**：把项目真实的文件夹列出来
- **常用命令**：把"怎么跑嵌入 / 怎么跑提取 / 怎么跑测试"填进去

这两处填了，AI 才知道你的项目长什么样。**没填也能用，但效果差很多。**

## 二、怎么启动

### 方式 A：在 VSCode 里（推荐）

1. 用 VSCode 打开你的项目文件夹
2. 按 `` Ctrl+` `` 打开集成终端
3. 敲 `opencode` 回车

> ⚠️ **如果提示找不到 `opencode`**：PATH 改了但 VSCode 还没刷新。
> **完全退出 VSCode 再重开**（不是关窗口，要退干净），或者直接重启电脑。

### 方式 B：快捷键

在 VSCode 里：
- `Ctrl+Esc` —— 打开 opencode（已有会话就切过去）
- `Ctrl+Shift+Esc` —— 强制开一个新会话

## 三、你会得到两个"专家"

拷进去之后，除了默认助手，你还多了两个专用子智能体：

| 名字 | 干什么 | 权限 |
|---|---|---|
| **`@stego-tutor`** | 隐写**理论助教**。解释概念、划论文阅读范围、告诉你某个数学需不需要啃 | 只读，不会改你代码 |
| **`@stego-dev`** | **工程实现助手**。改代码、接 hstego、写嵌入提取脚本、调报错 | 能改文件，但每步先问你 |

**怎么叫它们**：在对话里打 `@`，会弹出补全列表，选一个。

```
@stego-tutor UNIWARD 里的"失真"到底指什么？我要学到什么程度？
```

```
@stego-dev 帮我用 hstego 写一个最简的嵌入脚本，输入 png 和一段文字
```

## 六、常见问题

### 报错：`因为在此系统上禁止运行脚本` / `UnauthorizedAccess`

**症状**（在 PowerShell 里敲 `opencode` 时）：

```
无法加载文件 ...\node_modules\.bin\opencode.ps1，因为在此系统上禁止运行脚本。
```

**原因**：不是 opencode 的问题。PowerShell 的默认执行策略是 `Restricted`，
而 npm 安装命令行工具时会生成三个启动器：`opencode`（bash）、`opencode.cmd`（cmd）、
`opencode.ps1`（PowerShell）。**PowerShell 会优先选 `.ps1`**，
于是被策略拦下来。

> 顺带说明：这是**所有** npm 装出来的 CLI 工具的通病，不是 opencode 特有的。

**已经帮你修好了**。执行的是：

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
```

含义：
- `-Scope CurrentUser` —— **只影响你这个用户**，不需要管理员权限，不动系统级设置
- `RemoteSigned` —— 本地写的脚本放行；**从网上下载的、没签名的脚本依然会被拦**，
  安全性只放宽了一点点

**如果哪天想改回去**：

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Undefined
```

**检查当前状态**：

```powershell
Get-ExecutionPolicy -Scope CurrentUser
```

### 报错：`opencode: 无法将"opencode"项识别为 cmdlet...`

PATH 还没刷新。**完全退出 VSCode / 终端再重开**（关窗口不算，要退干净进程）。

### 验证是否一切正常

```powershell
opencode --version      # 应该输出 1.18.31
opencode models deepseek  # 应该列出 deepseek-v4-pro 等
```
