## 一句话

做一个**图像隐写**桌面应用：把一段信息藏进一张图片里（肉眼看不出差别），再能把信息提取回来。
先跑通传统方法（UNIWARD + STC），再延伸到用 AIGC 生成模型做隐写。

## 技术底座（按依赖顺序，从下往上）

| 层 | 是什么 | 干什么用 | 掌握要求 |
|---|---|---|---|
| 理论：STC | Syndrome-Trellis Codes，最小失真编码 | 把消息编成"改动哪些像素"的最优序列 | **当黑箱用，不啃数学** |
| 理论：UNIWARD | 通用小波相对失真函数 | 算出每个像素"改了被发现的代价" | 懂输入输出即可 |
| 工程：hstego | https://github.com/daniellerch/hstego | 上述两者的 Python 开源实现 | 会调用，不重写 |
| 界面 | TODO（PyQt / Gradio / Streamlit？） | 给用户一个能点的窗口 | 待定 |
| 延伸：AIGC 生成式隐写 | 用扩散模型等生成载体 | 课题的创新点 | 最后做 |

**关键认知**：UNIWARD 决定「改哪里代价小」，STC 决定「在代价约束下怎么改最少」。两者是流水线的上下游。
