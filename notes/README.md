## 从这两份文档里抽出来的「一句话铁律」

1. **`extract()` 失败不抛异常**，只往 **stdout** 打 `WARNING` 然后写 **0 字节**文件。
   判失败只能靠产物（不存在 / 0 字节 / sha256 不符），**不能靠 `try/except`**。
2. **JPEG 域失败率 25%**，与载体尺寸、容量、纹理都无关，**无法预测**。
   重试要换编码质量：`q95 → q92 → q88 → 换载体`。
3. **重试有效是「扰动」不是「容量」**：double quantization 等价于换载体。
   实测容量一点没变（972 B → 972 B），但自检从失败变通过。
4. **`jpg_capacity()` 是密文预算**，不是原始载荷上限。密文长度 = `60 + len(zlib.compress(载荷, 9))`。
5. **`hstegolib` 不是线程安全的**：用模块级 `random.seed()` + `random.shuffle()` 选嵌入位置。
   所有原生调用必须用一把全局锁串起来，`redirect_stdout` 捕获 WARNING 也要在锁内做。
6. **错误口令 / 提取失败 / 图中无消息，三者症状完全相同**，都是「0 字节输出 + 一行 WARNING」。
   UI 文案不要断言"口令错误"。
7. **容量不能用尺寸估算**：同为 512×512 q90，`splash` 460 B vs `baboon` 1532 B，差 3.3 倍。
   （早期按尺寸递增的那组数字是用合成噪声图测的，已作废。）
8. **前端用 `hidden` 属性切换显示时，类选择器不要设 `display`**——
   类选择器优先级高于 UA 的 `[hidden]` 规则，`hidden` 会失效。全局加 `[hidden]{display:none!important;}`。
9. **dataclass 字段名别和方法名撞**——`progress: float` 字段会盖掉 `progress()` 方法，
   报 `TypeError: 'float' object is not callable`。
10. **跑长脚本一律加 `-u`**——重定向到文件后 stdout 是块缓冲，看不到中间进度。
